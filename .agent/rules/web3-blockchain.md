# Web3 Blockchain Rules

## TON Ecosystem Rules
- **Exclusivity:** Only support **TON Connect**. Do not implement WalletConnect or other chains/wallets inside the Telegram Mini App.
- **Burn Mechanics:** User token burns must be user-initiated (e.g., spending $LIGHTER for premium roles/cosmetics).
- Never hold private keys. Use the standard TON Connect flow to request transactions.
